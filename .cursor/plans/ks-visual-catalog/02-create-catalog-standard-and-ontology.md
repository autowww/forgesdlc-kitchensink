# 02 — Catalog standard and ontology

## Goal

Create `docs/design/catalog/` structure and human/agent-facing standard (README, contract template, ontology).

## Expected changes

- `docs/design/catalog/README.md` — hash rules, lifecycle, registry, contracts, relationships to enterprise standard + UX auditor/scorer; kit examples non-authoritative.
- `docs/design/catalog/contract-template.md` — aligned with kit template (front matter + purpose, anatomy, content rules, states, variants, a11y, enterprise rules, forbidden patterns, dependencies, screenshots, changelog).
- Subdirs: `page-types/`, `layouts/`, `pages/`, `sections/`, `components/`, `primitives/`, `styles/`, `diagrams/`, `interactions/`, `desktop-interfaces/`, `screenshots/`
- `docs/design/catalog/ONTOLOGY.md` — page type, layout, page instance, section, component, primitive, style, diagram template, interaction, desktop/studio surface; page-type principles per kit list.

## Validation

README links resolve; contract-template matches checklist tooling.

## Stop condition

Standard sufficient to add registry rows and contracts consistently.

## Risks

Over-long README; keep operational and link out.
