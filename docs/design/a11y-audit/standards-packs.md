# Standards packs

Per-profile **standards packs** are machine-readable JSON files that list every success criterion in a compliance scope and which **axe**, **DET**, or **AI** rules cover each criterion. They are generated by the website-a11y-auditor blender and used by compliance scoring and CI validation.

**Not legal conformance.** Same disclaimer as [compliance profiles](compliance-profiles.md).

## Location

After `npm run blend-rules` in `tools/website-a11y-auditor/`:

| Pack file | Profile |
|-----------|---------|
| `design-rules/standards-packs/wcag20a.pack.json` | WCAG 2.0 Level A |
| `design-rules/standards-packs/wcag20aa.pack.json` | WCAG 2.0 Level AA |
| `design-rules/standards-packs/wcag20aaa.pack.json` | WCAG 2.0 Level AAA |
| `design-rules/standards-packs/wcag21a.pack.json` | WCAG 2.1 Level A |
| `design-rules/standards-packs/wcag21aa.pack.json` | WCAG 2.1 Level AA |
| `design-rules/standards-packs/wcag21aaa.pack.json` | WCAG 2.1 Level AAA |
| `design-rules/standards-packs/wcag22aa.pack.json` | WCAG 2.2 Level AA |

Source catalog: [`wcag-criteria-catalog.json`](wcag-criteria-catalog.json). WCAG 2.0 profiles reference [WCAG 2.0](https://www.w3.org/TR/WCAG20/).

## Regenerate

```bash
cd tools/website-a11y-auditor
npm run blend-rules
# or packs only (requires existing registry + matrix inputs):
npm run build-standards-packs
```

## Validate (CI)

```bash
node validate-standards-pack.mjs --pack wcag20aa
node validate-standards-pack.mjs --pack wcag20aaa --strict
node validate-standards-pack.mjs --pack wcag21a --strict
node validate-standards-pack.mjs --pack wcag21aa --strict
node validate-standards-pack.mjs --pack wcag21aaa --strict
```

`--strict` fails when `validation.uncoveredCriteria` is non-empty (automation gaps with no axe/DET/AI path). Use `--allow-manual-only` to permit gaps that are documented as manual-only in the catalog.

## Compliance score vs quality score

| CLI | Purpose |
|-----|---------|
| `score-compliance-a11y.mjs` | Roll up pass/fail/manual/gap **per success criterion** for a chosen pack |
| `score-website-a11y.mjs` | Sitewide **severity** penalty score (not SC-scoped) |

```bash
# Design-time automation coverage only
npm run score-compliance -- --compliance-profile wcag20aa --pack-only --out ./reports/wcag20aa

# Site crawl + criterion rollup
npm run score-compliance -- \
  --repo /path/to/site \
  --site http://127.0.0.1:8080 \
  --compliance-profile wcag20aa \
  --out ./reports/wcag20aa-site
```

Outputs: `compliance-score.json`, `criteria-results.json`, `compliance-score.md`.

## Pack schema (summary)

- `criteria[]` — each SC with `tooling` (`axe`, `det`, `ai`, `manual`) and `rules` by lane
- `rulesIndex[]` — all in-profile rules with `wcagCriteria`
- `validation.uncoveredCriteria` — SC with no automation path
- `summary.automationCoveragePercent` — design-time coverage metric

See `lib/build-standards-pack.js` for the builder.
