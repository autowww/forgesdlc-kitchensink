# Screenshots (generated)

PNG captures for catalog hashes are produced by:

```bash
# Serve showcase/ locally, then:
node tools/design-catalog/capture-showcase-screenshots.mjs --showcase-url http://127.0.0.1:4173/
```

Published convention: `https://ks.forgesdlc.com/showcase/screenshots/{HASH}.png`

Git may ignore large binaries; keep `screenshot_status: planned` in the registry until assets are committed or hosted.
