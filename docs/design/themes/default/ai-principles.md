# Default Theme AI Principles

The default theme uses the canonical AI review contract from
`docs/design/ux-audit/ai-enabled-design-principles.md`.

Theme-specific interpretation:

- The site should feel bold, spacious, enterprise-ready, and deliberate.
- Visual hierarchy should move from outcome to mechanism to trust evidence.
- Ambient and diagram layers should explain the governed system, not decorate it.
- Dense implementation detail belongs behind clear docs or reference paths.
- Trust copy should be bounded, operator-authentic, and free of invented claims.
- Repeatable AI findings should propose a candidate `DET.*` or catalog rule.
