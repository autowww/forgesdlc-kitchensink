# Forge default theme standard

This theme preserves the current Kitchen Sink / Forge enterprise AI design
language. The canonical behavioral and UX standard remains
`docs/design/forge-enterprise-ai-website-standard.md`; this file exists so
theme capture and audit tooling have a stable theme-local document to reference.

Use this default when no `--theme` is provided.
